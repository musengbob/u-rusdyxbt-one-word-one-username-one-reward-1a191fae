## The word

**sonder** — the realization that each random passerby is living a life as vivid and complex as your own.

One word, one username, one reward: every username on a leaderboard is a whole life behind a handle, and this is the word for the moment you notice that. Six letters, one sudden widening of the world.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt   # sonder
```

`main.ts` writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline, then reads it back and validates it byte for byte: exactly one word, 1–30 characters, letters only.
